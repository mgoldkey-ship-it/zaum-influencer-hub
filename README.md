# ZAUM // Influencer Hub — Операционный сервис работы с блогерами

Прототип рабочего сервиса для ежедневного управления рекламными интеграциями у блогеров (по демонстрационной таблице **ZAUM**).

## Почему выбрано такое решение
В исходной Google-таблице менеджеру приходится глазами выискивать зависшие согласования, вручную считать полный бюджет (размещение + себестоимость товара) и ориентироваться только на CPM по сторис (`=K2/I2*1000`), который не учитывает просмотры рилс и обзоров.

Поэтому на **первый экран** вынесены:
1. **Блок «Фокус дня» (Action Inbox)** — быстрые кнопки-фильтры в 1 клик по блогерам, где нужно уточнить дату выхода (`Нужна дата публикации`) или собрать статистику после выхода (`Проверить результаты`).
2. **Юнит-экономика кампании** — раздельный и суммарный учёт оплаты блогерам (`510 000 ₽`) и себестоимости отправленного товара (`33 600 ₽`), а также сравнение табличного `CPM по сторис` и эффективного `eCPM по просмотрам рилс/видео`.
3. **4 рабочих режима в 1 клик**:
   - **Реестр (Таблица на ПК / адаптивные карточки на телефоне)** с мгновенным поиском по артикулу (`DEMO-102`), фильтрами по площадкам (`Telegram`, `VK`, `YouTube`), форматам, ЦА и быстрым переключением статуса;
   - **Канбан-доска (Pipeline)** по 4 статусам (`Согласование` → `Запланировано` → `Опубликовано` → `Результаты получены`) с подсчётом бюджета на каждом этапе;
   - **Аналитика площадок + AI-аудит** с выводами по эффективности каналов (почему VK даёт минимальный eCPM видео ~472 ₽);
   - **Календарь выходов** по дням ноября 2026.
4. **Карточка интеграции с AI-шаблоном сообщения блогеру** — при клике на любого блогера можно отредактировать показатели (CPM пересчитывается автоматически по формуле таблицы) и в 1 клик скопировать готовое сообщение для отправки блогеру в Telegram под текущий статус сделки.

## Что бы улучшили дальше в боевой версии для ZAUM
1. **Двусторонняя синхронизация с Google Sheets API / БД (Supabase / PostgreSQL)** + история изменений по каждому блогеру.
2. **Связка с продажами WB / Ozon по артикулу (`Артикул`)**: подтягивать всплеск заказов и выручки по конкретному SKU в день выхода рекламы и считать реальный **DRR (ДДС / ROI)** каждого блогера.
3. **Telegram-бот уведомлений для инфлюенс-менеджера**: утренний дайджест «Сегодня выходят 2 блогера, по 3 интеграциям пора собрать скриншоты охватов».

## Быстрый запуск
- **Фронтенд (статический деплой GitHub Pages / Vercel / Netlify):** достаточно опубликовать `index.html` (все данные демонстрационной таблицы, фильтры, пересчёт CPM и сохранение правок работают прямо в браузере на ПК и мобильном).
- **Полный запуск с Python FastAPI бэкендом в Docker:**
  ```bash
  docker build -t zaum-influencer-hub .
  docker run -p 8000:8000 zaum-influencer-hub
  ```
- **Запуск автотестов:**
  ```bash
  pytest
  ```
